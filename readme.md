## Unity

Software version: `Unity 2021.3.6f1`

#### VFX package setup
```
1. Open a Unity project.
2. Open the Package Manager window (Window > Package Manager).
3. In the Package Manager window, in the Packages field, select Unity Registry.
4. Select Visual Effect Graph from the list of packages.
5. In the bottom right corner of the Package Manager window, select Install.
```

#### VFX creation

1. Create a VFX Graph (Asset menu)
   (!= Shader graph; Particle systems != Materials)
```
Creation Menu Location (It is not located under the "Shader" menu)

Right-click in the Project window and go to Create > Visual Effects > Visual Effect Graph
```

2. Drop to the Scene (Hierachy)

> Changes done during execution will not be saved. ( ▶ )
